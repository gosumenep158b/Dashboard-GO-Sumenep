# Dashboard GO Sumenep

Dashboard interaktif data siswa Bimbingan Belajar (GO) Kabupaten Sumenep untuk Tahun Ajaran 2026/2027.

## Fitur

- Overview: total siswa, grafik, top sekolah, tren pendaftaran, ulang tahun
- Data Siswa: pencarian, filter, pagination
- Ulang Tahun: daftar siswa berulang tahun bulan ini

## Menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:3000

Sumber data: Google Spreadsheet Master Data GO TA 26-27
